# 🌈 顏色小冒險

為三歲小女孩設計的顏色辨識手機遊戲。

## 🎮 遊戲特色

- **台灣女生中文語音**：使用 Web Speech API 的 zh-TW 台語女聲，溫柔鼓勵
- **完全語音驅動**：孩子不識字也能玩，所有引導靠發音
- **大觸控目標**：所有可點擊元素 ≥ 72px，適合小手操作
- **可愛風格**：柔和漸變背景、卡通動物角色、流暢慶祝動畫
- **錯誤零懲罰**：答錯不扣分、不顯示紅色叉，只用輕柔搖晃 + 重複發問
- **15 分鐘遊玩上限**：保護眼睛，時間到後溫柔結束

## 🎯 遊戲玩法

### 三關玩法
1. **找顏色**：屏幕顯示動物卡片，語音問「黃色在哪里？」，點正確顏色
2. **配對顏色**：動物說「我喜歡紅色！」，從氣球中選正確顏色
3. **顏色小球**：大螢幕上 6-8 個泡泡，語音「點點紅色泡泡！」，點對泡泡會破掉

### 顏色集（12 種）
紅、黃、藍、綠、橘、紫、粉紅、天藍、棕、灰、青綠、淡紫 — 每題隨機選 3-4 個顏色

### 動物角色（20 種）
小狗、小兔、小獅、熊貓、小雞、狐狸、貓咪、倉鼠、独角兽、青蛙、
考拉、小豬、小牛、猴子、蝴蝶、烏龜、海豚、螃蟹、烏賊、恐龍

## 📱 系統需求

- 支援 HTML5、Web Speech API、Web Audio API 的手機瀏覽器
- 建議使用：Chrome / Safari（最新版）
- 需要在支援 `zh-TW` 語音的裝置上開啟

## 🚀 快速開始

```bash
# 開啟遊戲（無需伺服器，直接開啟 HTML 即可）
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

或用本地伺服器：
```bash
python -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 🎙️ 語音系統

遊戲支援兩種語音模式：

### 模式 1：預錄語音檔（推薦）
- **優點**：無需手機語音包、離線可玩、語音品質穩定
- **使用方法**：
  ```bash
  # 安裝依賴
  pip install edge-tts
  
  # 生成語音檔
  python audio/generate_audio.py
  ```
- 生成後將 `audio/` 資料夾連同遊戲一起複製到手機

### 模式 2：Web Speech API（預設）
- 使用手機系統中文語音
- 需要手機已安裝中文語音包
- **Android**：設定 → 輔助使用 → 語言與輸入 → 語音轉換 → 下載「中文（繁體）」
- **iPhone**：設定 → 輔助使用 → 語音輸出 → 語音轉換 → 下載中文

**建議**：第一次使用時，遊戲會偵測語音可用性並提示安裝說明。

## ⚙️ 技術細節

### 檔案結構
```
childgames/
├── index.html              # 主頁面
├── README.md               # 說明文件
├── css/
│   └── style.css           # 樣式與動畫
├── js/
│   ├── audio.js            # 語音系統（TTS + Web Audio + 預錄檔支援）
│   └── game.js             # 遊戲邏輯與狀態機
└── audio/                  # 預錄語音檔案（選用）
    ├── manifest.json       # 語音清單
    ├── generate_audio.py   # 語音生成腳本
    └── *.mp3               # 生成的語音檔（需執行腳本）
```

### 關鍵技術
- **Web Speech API**：中文語音合成（zh-TW）
- **Web Audio API**：合成可愛音效（無外部檔案）
- **Pointer Events**：觸控互動（比 click 反應快）
- **CSS Animations**：彩帶、跳躍、搖晃效果
- **Responsive Design**：手機優先，支援 `safe-area-inset`

## 💡 給家長的小提醒

1. **語音設定**：建議手機設定為繁體中文，並下載中文語音包
2. **音量**：遊戲開始前建議調高音量，讓語音清晰
3. **15 分鐘限制**：遊戲會自動在 15 分鐘後結束，每 5 分鐘有語音提醒
4. **錯誤處理**：孩子答錯時不要糾正，遊戲會自動溫柔引導
